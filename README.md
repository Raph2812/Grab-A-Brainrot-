# GameScope

Application web statique de détection de jeux vidéo avec :

- recherche locale enrichie (incluant les jeux dans Roblox/Fortnite comme **Blox Fruits**),
- mode **recherche approfondie** (Wikipedia + Wikidata),
- filtre **jeux à venir**,
- design moderne responsive.

## Lancer

Ouvrir simplement `index.html` dans un navigateur moderne.

## Personnaliser la base locale

Modifier le tableau `METAGAME_INDEX` dans `script.js` pour ajouter vos jeux, plateformes et expériences.
